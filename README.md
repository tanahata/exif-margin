# EXIF Margin

写真をトリミングせずに白い余白を追加し、カメラ・レンズ・露出などの撮影情報を添えてJPEGで保存する、macOS・Android向けの無料アプリです。

## できること

- JPEG／PNGを読み込み、縦横比を保ったまま白いフレームを追加します。
- EXIFから機材名・焦点距離・F値・シャッター速度・ISOなどを読み取り、表示文字を修正できます。
- **元サイズ**：JPEG品質95／4:2:0。**SNS用**：品質90／4:2:0、完成画像の長辺2048px以下。どちらもsRGBで書き出します。
- 標準的な撮影EXIFを可能な範囲で保持し、GPS位置情報は引き継がない設計です。
- 元写真は上書きしません。処理は端末内で完結し、アカウント登録・広告・独自の写真アップロード機能はありません。

公開版の機材名は文字表示です。メーカー・機種の画像ロゴは含みません。

## 使い方

1. 写真を選択します。Androidでは他のアプリから写真を共有して開くこともできます。
2. 必要に応じて余白や表示文字を調整します。余白の初期値は元写真の短辺を基準に左右各2%、上7%、下20%です。
3. **Android**：画面下部で「元サイズ／SNS用」を選び、「JPEG保存」または「共有」を押します。**macOS**：対応する保存ボタンを押します。

新規インストール時の機材辞書は空です。機材名は写真のEXIFから読み取り、必要に応じて表示文字を編集・記憶できます。既存の機材辞書や設定はアプリ更新時に上書きしません。機材区分が未登録の場合は実焦点距離が表示されることがあるため、必要なら「35mm換算」を選択してください。

EXIFのない写真では撮影情報を自動表示できないことがあります。

## 対応環境・入手方法

| OS | 設定上の下限 | 検証済み環境 | 配布形式 |
|---|---|---|---|
| Android | Android 10（API 29） | Android 16／AQUOS R9 Pro | APK |
| macOS | macOS 12 | macOS 27.2／Apple Silicon | ZIP |

上記以外のOSバージョンやIntel Macでの動作は未検証です。公開後の配布ファイル・更新履歴・ハッシュ値は[GitHub Releases](https://github.com/tanahata/exif-margin/releases)で案内します。

**Android**：**Google Playなどのアプリストアには登録せず、GitHub Releasesで署名済みAPKだけを配布します**。GitHub ReleasesからAPKを取得し、公開されているSHA-256を確認してインストールしてください。端末の設定で、ダウンロード元アプリからのインストール許可が必要な場合があります。アプリの更新もGitHub Releasesから新しいAPKを手動で取得します。同じ署名のAPKで更新し、アプリのデータを保持します。OS標準の保護機能を無効化しないでください。

**2027年以降の注意**：Googleはストア外で配布するAPKにも影響する開発者確認制度を段階的に世界展開する予定です。これはGoogle Playへの登録とは別の制度です。未登録アプリのインストールには追加操作が必要になる場合があります。配布方法・確認制度の最新情報は[Android公式案内](https://developer.android.com/developer-verification/guides?hl=ja)で確認してください。現時点でPlay Console登録・ストア審査を行う予定はありません。

**macOS**：GitHub ReleasesでZIPを配布します。**Apple Developer IDによる署名と公証は行いません**（配布候補はad-hoc署名）。Appleによる開発元の確認や公証を受けたアプリではなく、初回起動時にmacOSから警告が表示される場合があります。

1. GitHub ReleasesからZIPを取得し、ファイル名と公開されているSHA-256を確認して展開します。
2. 展開した「EXIF Margin.app」を開きます。開発元を確認できないという警告で起動できない場合、入手元とファイルに問題がないことを確認してください。
3. 起動を試みた後、「システム設定」→「プライバシーとセキュリティ」→当該アプリの「このまま開く」を選び、表示された確認に従います。表示や操作はmacOSのバージョンによって異なる場合があります。

OS全体の保護を無効にする必要はありません。「アプリが破損している」「マルウェアを含む」などの警告が出た場合は回避せず、再ダウンロード・ハッシュ値・配布状況を確認してください。初回起動手順は[Apple公式「Macでアプリを安全に開く」](https://support.apple.com/ja-jp/102445)をご覧ください。
